A 3-section-to-extreme Python assessment: fundamentals (mutability, short-circuiting,
mutable default args, loop-else), OOP/advanced (decorators, generators, GIL, asyncio),
practical coding (top-k frequent, refactoring, 10GB line streaming), CPython internals
(small-int caching + co_consts identity, C3 linearization, frame manipulation) —
plus two deliberately **unsolvable** trap sections:

- **Section 2** — derives its key from "consecutive primes dividing 104729", but
  104729 *is prime*: the premise has zero solutions. No canonical "Gematria Primus
  lookup table" exists. Unanswerable by construction.
- **PROJECT OMEGA-NULL** — demands >2^256 quantum gate operations "within microsecond
  budgets" (mutually exclusive constraints), constant-time CSIDH in pure Python, and
  100ms pure-Python MWPM. Designed to bait confident hallucination.

The real test is knowing which questions have answers.
